# 少壮图片实验室

独立 MV3 本地测试插件，用来先跑通：

- 在主图、案例裂变等允许通用参考图的工作流中，上传参考图/竞品图并结合商品主体多角度图，反推风格、背景、景深、光影、字体字号、模特关系和中文提示词。
- 粘贴链接清单 JSON，按 `L001` 等编号分别生成主图或详情提示词。
- 通用参考图工作流以参考图和产品主体多角度图生成图片；Link/L 工作流按当前编号的链接定位与商品主体证据独立生成，两者不混用来源。
- 右键网页竞品图可一次性导入主图、SKU 或案例裂变等允许的通用参考槽位；正式参考成详不接收单图右键/context 导入。
- 链接清单批量工作流按编号范围执行，例如 `L001` 到 `L1000`：先顺序生成并展示每条独立提示词，再按每条自己的提示词最多 3 路并发生图。
- 同一条链接批量生成 4 个方向，并一键下载。
- 结果卡片支持复制图片、弹窗填写最高权重视觉引导词并重新生成、单张下载。
- 生图参数区支持终止当前生图和一次取消所有在途编号任务；主插件的 API 配置统一放在插件启动界面，独立实验室才使用本页配置弹窗。
- 详情生成独立成页：Link/L 详情保持按编号规划并结合商品主体素材生成；参考成详只接受淘宝/天猫商品 URL 或受支持当前商品页提取的 `REFERENCE_DETAIL_SOURCE_V1`，经 approved blueprint、事实与授权素材核验、显式审批及后台 registered batch 后生成 5–16 屏。旧 1–6 张手动参考图和单图右键/context 详情入口不会进入参考成详。
- 批量 SKU 独立成页：对象 SKU 原图作为不可变底图，当前产品图作为替换主体；只替换原商品主体，画布、构图、背景、光影、文字、价格、标签和其他非主体细节保持原样。最多 20 个任务，业务标题按行映射并用于结果与 JPG 文件名，技术 SKU 编号不进入画面或文件名。
- 爆款裂变独立成页：图1只提供约 30% 的爆款视觉基因，图2锁定唯一产品，约 70% 重新设计并固定输出 1 张高端详情页单屏；图1的商品、包装、品牌、Logo 与模特身份不得进入结果。
- 本机成果档案：所有成功生图自动以真实 Blob 留存在当前账号的浏览器本机 IndexedDB，可检索、预览、下载和移至回收站；回收站保留 7 天后由后台自动清理。档案 Blob 不存在时历史不展示空记录，普通下载文件夹中的副本不受影响。

## v0.4.40 · 事实卡自动仿写

- 一张事实卡代表一个自家商品，不代表一屏；同一商品生成 10 屏详情时只需 1 张事实卡。
- 系统只会以同名且已完整填写的自家商品事实卡为依据，自动仿写并补齐目标卡中为空的产品名、产品特性和核心卖点。
- 自动仿写不会覆盖任何已有的用户内容；仿写结果可以直接修改，不需逐卡确认。
- 参考页和竞品详情只用于分析页面结构，其商品事实、品牌、规格、材质、认证和卖点严禁用于自家事实卡的自动仿写或补齐。

## 本地加载

1. 打开 `chrome://extensions/`。
2. 开启「开发者模式」。
3. 点「加载已解压的扩展程序」。
4. 选择本目录：`labs/image-prompt-lab`。
5. 点扩展图标打开工作台。

## 接入的服务商预设

并入主插件时，点页面顶部「统一 API 设置」会打开插件启动界面的唯一配置中心；各工作台重新获得焦点时会载入最新账号 profile。只有把本目录作为独立扩展加载时，才使用页面内的「独立版 API 配置」。API Key 只保存在本机当前账号的 `chrome.storage.local` profile，不会写入源码、共享预设或链接清单任务。

已内置预设：

- 千问 / DashScope：`qwen-vl-plus` 提词，`wan2.7-image` 生图。
- DeepSeek V4：文本/链接清单提词；不做图片反推和生图。
- MiniMax：保留文本/视觉提词入口；当前商品多角度工作流不启用其人物主体参考生图接口。
- 智谱：GLM 视觉/文本 + CogView 生图适配器。
- 豆包 / 火山方舟：`doubao-seed-evolving` 提词 + Seedream 生图适配器，默认生图模型为 `doubao-seedream-5-0-260128`。
- ChatGPT / GPT Image 2：OpenAI chat/vision + `gpt-image-2` Images API。
- Nano Banana / Gemini：Gemini 图片模型 `generateContent` 适配器。
- 少壮 AI 网关 / OpenAI 兼容：默认走 `https://sub.shaozhuangai.com/v1`，文本模型 `chatGPT5.5`，生图模型 `image2`，也可手动切换为其它 OpenAI-compatible 模型。
- 旧版本若把少壮托管提词模型保存成已失效的 `chatGPT5.6`，工作台会在载入时把 legacy、全局和各账号配置一次性迁移为 `chatGPT5.5`；自建兼容网关不参与该迁移。其他未开通模型会显示可操作的中文 `model_not_found` 提示，不再回显原始 HTTP JSON。
- 官方托管通道若返回其他文本模型不存在（例如 `GPT-5.6 Luna`），会对当前账号仅重试一次默认 `chatGPT5.5`，成功后写回当前账号；不会改写其他账号或自建网关。图片模型不存在时只返回中文 `image_model_not_found`，不把文本模型当作图片模型回退。
- 官方少壮文本端点会把误填的 `gpt-5.5` 转为网关别名 `chatGPT5.5`，官方少壮生图端点会把 `gpt-image-2` 转为 `image2`；文本和图片端点分别判断，因此混合使用自建端点时不会误改。托管候选列表仅展示网关别名，`gpt-*` 候选保留给 ChatGPT 直连来源。

默认按少壮 AI 网关配置：

- 视觉/提词：`https://sub.shaozhuangai.com/v1`
- 提词模型：`chatGPT5.5`
- 文本模型：`chatGPT5.5`
- 生图 Endpoint：`https://sub.shaozhuangai.com/v1/images/generations`
- 生图模型：`image2`

统一设置 / 独立版配置里保留可输入的备选清单：文本/视觉包含 `chatGPT5.5`、`gpt-5.5`、`gpt-5-mini`、`gpt-4o-mini`、`doubao-seed-evolving`、`deepseek-chat`、`deepseek-reasoner`、`deepseek-v4-flash`、`qwen-vl-plus`、`glm-4v-plus`、`MiniMax-M2.1`；生图包含 `image2`、`gpt-image-2`、`gpt-image-1.5`、`gpt-image-1`、`doubao-seedream-5-0-260128`、`cogview-4-250304`、`image-01`、`wan2.7-image`、`nanobanana-2`。

部分平台的模型 ID 会随账号区域、白名单或版本调整。预设只是起点，实际以控制台开通的模型名为准；主插件请在启动界面的统一设置里修改。

火山 Seedream 5.0-lite 需要 2K/3K 级别尺寸。实验室里保留了旧的 1024/768 测试尺寸，但通过火山生图时会自动映射为同构图比例的 2K 尺寸，例如 `768*1024` 会转为 `1728x2304`。

通用主体替换逻辑：在主图、案例裂变等允许通用参考图的工作流中，如果同时提供「参考图 / 竞品图」和「产品主体图」，提词和生图会进入主体替换模式。产品主体图支持正视图、侧视图、背视图三张证据图，三张图共同定义最终商品主角及真实几何比例；参考图只借用构图、镜头、景深、光线、色彩、背景、字体字号、模特关系和商业版式，不再把参考图里的旧产品作为最终主体。正式参考成详不使用这条通用上传适配器，而是从已审批蓝图、核验事实卡和自有/授权目标素材重建。智谱 CogView 的文字-only 生图路径与 MiniMax 的人物主体参考接口都不适合商品多角度一致性，因此会被阻止并提示切换，避免静默丢失或误用主体证据。

最高权重引导词不是简单追加到提示词最前面，而是作为提示词工程里的语义裁决层：当它和参考图、旧结果图、链接提词或历史提示词冲突时，引导词语义优先；落地方式要求模型把它转译为自然画面调整，例如替换容器、弱化冲突道具、重排空间、调整遮挡关系，而不是把引导词硬贴进画面。

1. 导入关键词原表

支持 CSV「关键词,人气,来源」和 SW 标准 sources JSON。区间或空白人气会保留为缺失；每文件最多 5 MB。

2. 人工确认词根

拆词与生成说明

用 | 分开词根，拼合后必须覆盖原关键词，再为每个词根选择类型。点击保存表示人工确认。没有模型调用；关键词与词根导出不等于链接评分结果。

超过 200 个词可下载完整记录和分析分批计划，导入完整人工注释 JSON。一次评分最多 200 个去重词。

3. 用市场原表生成链接草稿

仅接受同范围的生意参谋商品榜 JSON。精确人气、完整词根和完整市场样本缺一项都会明确停止；草稿需复核商品事实与标题。

文件知识库 · 文本检索

TXT / Markdown / JSON 可直接检索；PDF、DOC、DOCX、XLSX 暂存为待解析；图片保存原件，不进行 OCR。当前没有接入智能体或向量检索。
